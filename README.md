# Бот Telegram-канала со скидками на игры Steam

Бот каждые 10 минут проверяет популярные скидки Steam: лидеров продаж, новинки и специальные предложения. Публикует не более пяти постов за одну проверку (`MAX_POSTS_PER_CHECK`), ранжируя скидки по порядку популярности в подборках Steam, а затем по размеру скидки. Также ищет популярные free-to-play игры и публикует не более одной новой игры в день. В пост добавляются обложка, срок акции (если известен) и кнопка перехода в Steam.

Если скидка закончится и появится снова — в том числе по той же цене — бот сообщит об этом повторно; также он сообщит о снижении цены в рамках текущей акции. Для F2P-игр действует отдельная история: каждая игра публикуется только один раз.

Steam не предоставляет через используемый интерфейс точное поле о том, засчитывается ли игра для значка «Коллекционер игр». Поэтому бот использует приближённый фильтр: исключает игры без исходной цены и включает платные игры, временно ставшие бесплатными. Это не гарантирует соответствие требованиям значка для каждой игры или аккаунта.

Список популярных бесплатных игр берётся из поиска Steam с фильтром бесплатных игр. Новые игры публикуются по одной в день; каждая игра публикуется только один раз. Результаты Steam могут включать временные бесплатные акции и не гарантируют идеальную классификацию каждого тайтла.

## Запуск на компьютере

1. Установите Python версии 3.11 или новее.
2. Установите зависимости командой `python -m pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и укажите токен Telegram-бота и ID канала. Добавьте бота в канал администратором с правом публиковать сообщения.
4. При необходимости укажите в `ADMIN_USER_IDS` ID администраторов Telegram через запятую — им будет доступна команда `/check` и уведомления об ошибках. Администратор должен хотя бы раз открыть чат с ботом и отправить `/start`, чтобы бот мог написать ему первым.
5. Запустите `python bot.py`. Настройки будут загружены из файла `.env` в текущей папке. Чтобы выполнить одну проверку и завершить работу, запустите `python bot.py --once`.

## Запуск на GitHub Actions

1. Создайте бота через [@BotFather](https://t.me/BotFather), добавьте его в канал администратором и разрешите публикацию сообщений.
2. В репозитории GitHub откройте **Параметры → Секреты и переменные → Actions** и добавьте секреты репозитория:
   - `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
   - `TELEGRAM_CHANNEL_ID` — имя канала, например `@имя_канала`, или его числовой ID.
   - `ADMIN_USER_IDS` — необязательный список ID администраторов Telegram через запятую для уведомлений об ошибках. Каждый администратор должен заранее открыть чат с ботом и отправить `/start`.
3. Откройте **Параметры → Actions → Общие → Разрешения рабочего процесса** и разрешите чтение и запись. Это нужно сценарию, чтобы сохранять историю публикаций в SQLite и не размещать повторы.
4. Включите Actions для репозитория. Автоматическая проверка выполняется каждые 10 минут. Запустить её вручную можно через **Actions → Публикация скидок Steam → Запустить рабочий процесс**.

Перед каждой проверкой GitHub Actions запускает тесты. Сетевые запросы к Steam и отправка постов повторяются при временных ошибках с увеличением паузы. История скидок, уже опубликованные F2P-игры и дневной лимит сохраняются в SQLite и отправляются в приватный репозиторий после проверки. При высокой нагрузке GitHub может запускать задачи по расписанию с задержкой.

При локальном запуске в режиме постоянного опроса Telegram бот также поддерживает команду `/start` и команду `/check`, доступную только администраторам, указанным в `ADMIN_USER_IDS`.
